# AutoStock - A股自动化分析工具

## 安装
```bash
pip install pandas numpy matplotlib httpx beautifulsoup4
```

## 使用

### 股票分析
```bash
python3 autostock.py 600519 000858 300750
```

### 数据采集
```bash
python3 data_harvest.py fetch "https://example.com"
python3 data_harvest.py links "https://example.com"
```
